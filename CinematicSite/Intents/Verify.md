# Verify

Проверенный сайт и доказательства того, что он читается и работает на компьютере и телефоне.

## Ideal State

- Сборка и статическая проверка проходят на конкретном проекте; перед выкатом нет заглушек, непереведённых текстов и адресов превью.
- В настоящем браузере просмотрены все разделы на 1440 px и 390 px; для 3D просмотрены кадры каждой остановки и движение между ними. Текст не наезжает на 3D, кнопки доступны, горизонтальной прокрутки нет.
- Для готового мира проверены обычный режим, reduced-motion, отсутствие JavaScript и недоступность внешних скриптов. Без WebGL и при потере контекста остаётся полезная страница.
- Постер виден до воспроизведения видео, видео останавливается вне кадра. Неактивная вкладка и пауза не расходуют кадры мира.
- Загрузка измерена с холодным кешем; бюджет по умолчанию — 6 МБ первой загрузки без сжатия локального превью, three.js до 200 КБ gzip. Если согласован другой бюджет, он явно записан в брифе.
- Независимый рецензент без контекста сборки получил бриф, выбранное направление и превью, сравнил сайт с референсами; находки исправлены либо явно разобраны с причиной.

## Anti-criteria

- Чужое превью на занятом порту засчитано как этот сайт; число или HTTP 200 заменило просмотр кадров.
- Скриншот скрытой вкладки или DOM-снимок без WebGL выдан за настоящее изображение мира.
- Неисполненная проверка, симуляция телефона или недоступный рецензент названы пройденной проверкой реального устройства.

## Tool contract

В проекте:

```bash
bun run build
bun run verify
bun run verify -- --release --forbid preview.example.com
```

Дополнительная автоматическая диагностика из папки навыка:

```bash
bun Tools/Check.ts --url http://127.0.0.1:4321/ --expect-title "Demo Studio" --out /tmp/site-check --force-world
```

Инструмент использует Chrome через CDP и сохраняет `report.json` и снимки. Его ограничения перечислены в `Tools/Check.help.md`: автоматическая диагностика не заменяет настоящий браузерный просмотр. В среде, где браузер разрешён только через Interceptor, финальная и дополнительная браузерные проверки идут через Interceptor; `Check.ts` там не запускается.

### Intent-to-Flag Mapping

| Проверка | Флаг |
|----------|------|
| 3D-мир | `--force-world` |
| Страница без мира | `--allow-no-world` |
| Снижение движения | `--reduced-motion` |
| Внешние скрипты Astro недоступны | `--block-js` |
| Нет JavaScript | `--no-js` |
| Только один размер | `--desktop-only` или `--mobile-only` |
| Бюджет загрузки | `--max-initial-mb 6` |
| Отдельный Chrome/CDP-порт | `--port 9445` |

## Output format

Итог pass/fail, адрес и заголовок проверенного сайта, кадры каждого раздела на компьютере и телефоне, результаты запасных путей, ограничения устройства/эмуляции и перечень незакрытых находок. Недоступные проверки остаются открытыми.
