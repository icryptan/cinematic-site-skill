# Ship

Доступное получателю превью либо согласованный выкат с архивом и проверкой работающего сайта.

## Ideal State

- Превью собрано отдельной командой `bun run build:preview`, закрыто от индексации настройкой сервера, не затрагивает рабочий сайт и открывается у получателя. В каркасе команда только задаёт `PUBLIC_PREVIEW=1`; обработка домена и API при необходимости реализуется в конкретном сайте.
- Перед заменой работающего сайта записан слепок страниц, ключевых ссылок, переходов до оплаты и читаемых данных; определена ветка, из которой собрана текущая версия.
- Пробный прогон выката показывает только согласованные изменения. Архив текущей версии проверен, команда отката записана, нужные серверные файлы сохранены.
- Боевая сборка не содержит адресов превью. Все страницы отдают её ресурсы или метку сборки три прохода подряд, включая запросы без параметров и путь через CDN.
- Ссылки, основные действия и данные совпадают со слепком, новая версия просмотрена в настоящем браузере на компьютере и телефоне. Отчёт содержит коммит и команду отката.

## Anti-criteria

- Выкат без согласия владельца, реальные платежи или сообщения клиентам во время проверки.
- Потеря страниц, пользовательских данных, почтовых каталогов или соседних сервисов из-за массовой синхронизации.
- Превью опубликовано вместе с закрытым брифом, секретами или материалами без разрешения на раскрытие.

## Inputs

Одобренный сайт после `Verify`, адрес назначения, разрешение на конкретное действие, доступ к согласованному хостингу. Инфраструктура и секреты принадлежат установке владельца; в пакет они не входят.

## Safety gates

- Внешнее размещение, новый сервис и выкат разрешаются отдельно. Генерация сайта не означает разрешения на публикацию.
- Ключи хранятся в менеджере секретов или окружении; не в URL, репозитории и отчётах.
- Потеря работоспособности после выката вызывает откат до отчёта об успехе. Удаление данных и переписывание истории требуют отдельного согласия.

## Tool contract

Превью из проекта:

```bash
bun run build:preview
PORT=4321 bun run preview
```

`PORT` должен быть свободным; без него сервер выбирает случайный порт. Сервер раздаёт `dist/`, ограничивает методы GET/HEAD, скрытые файлы и пути за корнем, поддерживает Range для видео. Он слушает все интерфейсы — доступ к сети и внешнему туннелю настраивает владелец. `noindex` не является защитой доступа; закрытым материалам нужен контроль доступа хостинга.

Для боевого адреса: `bun run build` и `bun run verify -- --release --forbid preview.example.com`. Команда выката зависит от выбранного хостинга и готовится с пробным прогоном, архивом и откатом.

### Intent-to-Flag Mapping

| Действие | Параметр | Результат |
|----------|----------|-----------|
| локальное превью | `PORT=4321` | явный порт сервера |
| проверка боевой сборки | `--release` | нет следов каркаса |
| исключить хост превью | `--forbid preview.example.com` | адрес не попадает в сборку |

## Output format

Ссылка на проверенное превью либо адрес выката; коммит, результат сверки со слепком, просмотренные кадры и команда отката. Открытые проверки и ограничения названы явно.

## Evals

- compiled: проверка конкретного выката против слепка и просмотр браузером; наличие файлов и ответ сервера сами по себе не означают успешный выкат.
