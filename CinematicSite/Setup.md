# Установка CinematicSite

## What it does

Навык помогает собрать бриф и референсы, выбрать направление, создать сайт и проверить результат. `Kit/` — нейтральный Astro-каркас. Готовые сцены, клиентские материалы, платные сервисы и настроенный хостинг не поставляются.

## Fill in

Нужны Bun и Git. Для браузерной диагностики — Google Chrome; на Linux/Windows путь задаётся через `CHROME_BIN`. Для генератора Chrome не требуется. Установка — копирование всей папки `CinematicSite` в каталог навыков своего агента, вместе с `Kit/`, `Tools/`, `Intents/` и `References/`. Каталог выбирается по документации агента.

Без установки в агент из этой папки выполняется `bun Tools/NewSite.ts --help`. Название, домен и языки задаются флагами; материалы и предпочтения проекта хранятся в `docs/`. Исходный пакет не заполняется личными данными.

## Accounts and secrets

Для генерации аккаунты и API-ключи не нужны. По умолчанию генератор вызывает `bun install` с обращением к реестру пакетов; `--no-install` отключает этот шаг. 3D-библиотеки и ассеты выбираются для нового проекта отдельно.

Платная генерация, внешний хостинг и деплой требуют собственных аккаунтов и разрешения владельца. Ключи — в менеджере секретов или окружении. Пакет сам ничего не отправляет в модель и аналитику; запросы агента зависят от среды запуска. `Check.ts` загружает указанный сайт и его ресурсы в Chrome.

## Prove it works

Из папки навыка, выбрав ещё не существующий каталог:

```bash
bun Tools/NewSite.ts --name demo-site --brand "Demo Studio" --dir /tmp/demo-site --no-git
cd /tmp/demo-site
bun run build
bun run verify
bun run preview
```

Последняя команда печатает свободный порт и запускает сервер на всех интерфейсах. Это каркас, а не готовый дизайн. `bun run verify -- --release` намеренно отвергает его до замены заглушек. Полная проверка — `Intents/Verify.md`; ограничения автоматики — `Tools/Check.help.md`.
