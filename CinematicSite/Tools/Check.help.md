# Check.ts

Дополнительная диагностика через Chrome DevTools Protocol. Создаёт `report.json` и кадры 1440×900 и 402×874 DPR 2; проверяет заголовок, ошибки, классы загрузки, h1, первую загрузку и наличие мира.

```bash
bun Tools/Check.ts --url http://127.0.0.1:4321/ --expect-title "Demo Studio" --out /tmp/site-check --allow-no-world
```

URL обязателен. Для 3D — `--force-world`; один размер — `--desktop-only` или `--mobile-only`; запасные режимы — `--reduced-motion`, `--block-js`, `--no-js`; частота кадров — `--every 3`; бюджет — `--max-initial-mb 6`; CDP-порт — `--port 9445`.

`CHROME_BIN` задаёт исполняемый файл Chrome; по умолчанию стандартный путь macOS. Инструмент запускает headless Chrome с отдельным одноразовым профилем, если на CDP-порту нет сервера. Созданный им профиль удаляется при обычном завершении и обрабатываемой ошибке; при аварийном завершении процесса временная папка может остаться. Используйте свободный порт, не чужой отладочный браузер: чужой профиль инструмент не удаляет. Chrome загружает указанный сайт и внешние ресурсы.

## Ограничения

- Диагностика не является приёмкой визуала. Нужен настоящий браузер и отдельная проверка на 390 px. В среде только с Interceptor скрипт не запускается.
- `scrollWidth` сравнивается с `innerWidth`; эмуляция иногда расширяет оба. Нужна независимая сверка с заданной шириной устройства.
- `--block-js` блокирует только `_astro/*.js`. Для `app.js` или другой упаковки нужен собственный сценарий. «Не применимо» не считается успехом.
- При smooth scroll снимок может попасть в движение. Это не тест стабильности анимации.
- reduced-motion, нет WebGL и потеря контекста — разные режимы; последние два проверяются отдельно.
- Зависание Chrome оставляет проверку незавершённой. Отсутствие отчёта не считается успехом; реальный телефон этим инструментом не проверяется.
