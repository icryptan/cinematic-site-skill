# NewSite.ts

Копирует нейтральный `Kit/`, задаёт бренд, favicon, URL и языки, при необходимости устанавливает зависимости и создаёт git-коммит.

```bash
bun Tools/NewSite.ts --name demo --brand "Demo Studio" --dir /tmp/demo --no-git
```

| Флаг | Значение |
|------|----------|
| `--name` | обязательное имя проекта, приводится к латинскому slug |
| `--brand` | название; по умолчанию из slug |
| `--mark` | знак favicon; по умолчанию первая буква названия |
| `--dir` | новый каталог; по умолчанию `./<slug>` |
| `--url` | HTTP(S) адрес; по умолчанию `https://example.com` |
| `--locales` | коды и hreflang, например `en,pt:pt-PT` |
| `--kit` | другой нейтральный каркас; при наличии `.git` экспортируется его `main` |
| `--no-install` | без `bun install` и обращения к реестру |
| `--no-git` | без git-истории |
| `--help` | справка |

В существующий каталог генератор не пишет. Языковые тексты сначала копируют английские; до выпуска нужен перевод. Палитру, шрифты, разделы и мир задаёт направление.
