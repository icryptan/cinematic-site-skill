# Приёмы — из чего собирается сайт

Движок выбирается по истории бренда. `Kit/` содержит только нейтральный Astro-каркас, токены, раскрытия, локализацию и запасной путь загрузки. Готовые сцены, модели, видео, библиотека three.js и код прошлых проектов не входят в комплект.

## Движок истории

| Движок | Когда подходит | Результат |
|--------|----------------|-----------|
| Постоянный 3D-мир | Бренду полезно пространство, живой свет и объём | один мир, камеру ведут главы истории |
| Видео или кадры по прокрутке | Есть съёмка продукта и нужен фотореализм | последовательность кадров с доступным постером |
| DOM-движение | Историю несут фото и типографика | раскрытия и сцены без тяжёлого мира |
| Гибрид | Редакционный коллаж с лёгким 3D-слоем | фотографии и текст сохраняют главное место |

На сайте один движок плавной прокрутки и один владелец каждого анимируемого свойства. Палитра и ритм берутся из `tokens.css`.

## Механизмы

| Механизм | Контракт | Цена на телефоне |
|----------|----------|------------------|
| Камера по якорям | DOM-разделы описывают остановки `data-cam`, мир читает их координаты | низкая |
| Узкий экран | предмет сверху, текст ниже; положение отражается в `--hero-media-bottom` | низкая |
| Регулятор кадров | сначала снижает DPR, затем частицы, затем переключает на обычную страницу | экономит ресурсы |
| Запасные пути | нет WebGL, reduced-motion, потеря контекста → полезная страница без мира | обязательны |
| Цвета из CSS | мир и страница читают одни токены | низкая |
| Видео | постер до воспроизведения, пауза вне кадра и в скрытой вкладке | средняя |
| Пауза рендера | мир не рисуется, когда закрыт, скрыт или поставлен на паузу | экономит батарею |
| Раскрытия текста | `src/scripts/boot.ts`; без скриптов текст виден | низкая |
| Магнитные кнопки и наклоны | только для точного указателя, обычный контрол доступен | отключены на сенсорных |
| Карусель | свайп, клавиатура, стрелки, пауза при фокусе и наведении | низкая |
| 3D внутри DOM-блока | холст движется с блоком; viewport/scissor для его прямоугольника | низкая–средняя |
| Рябь и жидкое стекло | поле высот в ping-pong render targets, фото преломляется по градиенту | средняя |
| Хром | отдельная отражаемая среда, контрастные источники, CubeCamera с правильными слоями | средняя |
| Повторяющийся декор | InstancedMesh и Points вместо отдельного Mesh на каждый объект | низкая |

## Оригинальность

Код общих механизмов и узнаваемый визуал — разные вещи. Предыдущий сайт не превращается в шаблон для смены бренда. Для каждого референса записаны защищённые элементы; новая композиция, предметы, палитра и метафора выводятся из нового брифа.

## Дополнительная библиотека

Общедоступные методики по ссылкам в `References.md` — необязательные справочники, а не поставляемый код или команды. Любой новый эффект проверяется на телефоне, с отключённым WebGL и reduced-motion.
