# Сообщить об уязвимости

Не публикуйте ключи, личные данные или рабочие ссылки в issue. Используйте Private vulnerability reporting во вкладке Security репозитория, если функция включена. Если она недоступна, откройте issue только с просьбой предоставить закрытый канал, без технических подробностей и секретов.

Перед отправкой снимков и логов удалите личные данные. Инструмент диагностики получает только адрес тестируемого сайта; не передавайте ему чужие закрытые страницы и отладочные браузерные профили.
